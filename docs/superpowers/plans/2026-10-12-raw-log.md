# Raw Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every event ingest stores in SQLite is also appended to a per-project, per-day NDJSON log under `<data>/raw/`. The daily pass dumps each closed day's log to Parquet, merges a final month's day files into one month file, and deletes month files past `RETENTION_DAYS`. Nothing reads the files yet.

**Architecture:** A new leaf package `internal/archive` holds the log (`Log`, a `pipeline.Sink`) and the file maintenance (`Archive.Maintain`). The maintenance drives the PR 2 engine with `Exec` (`COPY … TO …parquet`). The pipeline writes each batch to SQLite and then to the log through `pipeline.Sinks`. Approved form submissions, which bypass the pipeline, reach the log through a decorator in `app`. The daily pass runs the maintenance in the ingest process, after a random delay of up to 30 minutes when scheduled. Before the engine gets this caller, the first two tasks close PR 2's entry conditions:
- `Query` accepts one `SELECT` only;
- the spill directory is capped;
- `Close` answers `ErrClosed`;
- an idle child yields its slot to a waiter;
- the child is spawned from `/proc/self/exe`.

**Tech Stack:** Go 1.25, `internal/engine` (DuckDB v1.5.6 in a child process), `encoding/json`, `syscall` (flock), the existing pipeline, jobs and config packages.

**Spec:** `docs/superpowers/specs/2026-10-12-raw-first-design.md`: D2 (log, dedup, dump, merge, no index), D3 (late window), D5 (retention by file), D6 (a purged project deletes its directory), D7 (backups by hand), D8 (the engine), D23 (`RETENTION_DAYS`). Roadmap: `docs/superpowers/plans/2026-10-12-raw-first-roadmap.md`, PR 3, including "Entry conditions from PR 2's review".

## Facts this plan rests on (probed 2026-10-12, DuckDB v1.5.6 via duckdb-go v2.10506.0)

- **`read_ndjson(path, sample_size=-1)`** over lines shaped like the plan's: `id` infers as `UUID`, `ts` as `TIMESTAMP` (from `"2026-10-12T01:02:03Z"`), `day` as `DATE`, `project_id` and `v` as `BIGINT`, `value` as `DOUBLE`, every `attr_*` as `VARCHAR`.
  - A field absent from some lines reads as NULL there.
  - An empty file reads as 0 rows.
- **The dump and the merge both work as written below.**
  - The dump, `COPY (SELECT DISTINCT ON (id) * FROM read_ndjson(…) ORDER BY family, ts) TO '…parquet' (FORMAT parquet, COMPRESSION zstd)`, drops duplicate ids.
  - The merge reads `read_parquet([...], union_by_name=true)`, joining files with different `attr_*` columns.
  - `parquet_file_metadata(file).num_rows` gives a file's row count from its footer.
- **A torn last line** (a partial JSON object) makes `read_ndjson` fail. With `ignore_errors=true` it is counted as an extra row. So a log must be cut back to its last newline before anything reads it.
- **DuckDB column names are case-insensitive.** A log holding `attr_Plan` and `attr_plan` infers the second as `attr_plan_1`, in line order. That is a known gap, below.
- **Preparing a multi-statement string runs every statement but the last.** Preparing `COPY (SELECT 1) TO 'x.csv'; SELECT 1` wrote the file, and its statement type read as SELECT. So a read-only check must not prepare.
  - `json_serialize_sql(CAST(? AS VARCHAR))` parses without running anything. It returns `{"error":true,"error_type":"not implemented",…}` for any non-SELECT (COPY, CREATE, ATTACH, PRAGMA, EXPLAIN, multi-statement with a non-SELECT).
  - It returns `"statements":[…]` with one entry per statement for `SELECT 1; SELECT 2`.
  - It returns `{"error":true,"error_type":"parser","error_message":"syntax error at end of input",…}` for bad syntax.
  - `DESCRIBE`, `SHOW`, `SUMMARIZE`, `FROM t` and `VALUES` parse as one SELECT.
- `SET GLOBAL max_temp_directory_size = '4GB'` reads back as `3.7 GiB`.

## Global Constraints

- **Events are written to SQLite as today and to the log; nothing reads the files yet** (roadmap PR 3). SQLite stays the source of truth in this release. No query, widget or `usage` path changes.
- **Log layout under `<data dir>/raw/<project_id>/`:**
  - `<YYYY-MM-DD>.log` is the open log;
  - `<YYYY-MM-DD>.parquet` is the day file;
  - `<YYYY-MM-DD>.<n>.parquet` is a late segment;
  - `<YYYY-MM>.parquet` is the month file (D2, roadmap).
- **The line has the Parquet row's shape** (D2, Q10):
  - the events table's column names as fields;
  - attributes flat as `attr_<key>` with string values;
  - fields omitted when absent;
  - `"v": 1`.
- Appends go through one `O_APPEND` descriptor per open log. At each pipeline flush the log is fsynced. At boot a log is truncated to its last newline (D2).
- Dedup belongs to the dump and the merges (`DISTINCT ON (id)`). Ingest keeps the ids of the last 10 minutes to keep retries out of the log (D2).
- Merge a month once its last day is past `INGEST_LATE_DAYS` (D2, D3).
- `RETENTION_DAYS`, default 400, deletes whole month files (D5, D23). `RETENTION_RAW_DAYS` and `RETENTION_AGGREGATE_DAYS` keep governing SQLite until PR 6.
- A purged project deletes its directory (D6).
- Jitter in the daily pass: dumps and merges spread over a window rather than all starting at 03:00 (D8).
- No index: the directory is the list of files (D2).
- `internal/archive` is rank 0 in `internal/archtest` (a leaf that imports the leaves `engine`, `store`, `shared/civil`). `jobs` and `app` consume it, `jobs` through an interface it declares (CLAUDE.md Layout).
- Docs in the same commit as the change: env vars in `docs/deployment.md` (bound by `TestDeploymentDocumentsEveryEnvVar`), the data directory and backups in `docs/deployment.md` and `docs/litestream.md`, upgrade-day changes in `deploy/UPGRADES.md` (CLAUDE.md "Documentation").
- `make check` before every push.

## Decisions this plan takes (review them)

1. **Attribute keys go into the line unsanitized.** The field is `attr_` + the key exactly as stored (any characters). JSON and Parquet carry such names, and nothing is lost or merged. Sanitized aliases (`flatview.go`'s rule) belong to the read side in PR 4, where the project's catalog gives a stable mapping.
   - Known gap, for PR 4: keys equal but for case collide in DuckDB (see Facts). PR 4's dump or views must spell out the columns from the catalog.
2. **Rules are already applied when an event reaches the pipeline.** Ingest resolves event renames, blocks and attribute rules from the registry snapshot before `Enqueue`. The log writes the events as they come. A rule changed during the ≤10 s an event waits in the buffer differs between SQLite (which re-applies renames in SQL) and the log. The spec applies rules on read (D6), so the files need not be exact here.
3. **Order: SQLite first, then the log, inside one retried write** (`pipeline.Sinks`). If the log fails, the batch is retried whole. SQLite ignores rows it already has. The log skips ids it wrote in the last 10 minutes. A failed write is cut back to the file's previous size, so no torn line is left mid-file.
4. **The file maintenance runs only in a process that ingests** (`serve` with the ingest surface). That process owns the log and its rotation. A split install's console process does no file work.
5. **The read-only guard is `json_serialize_sql`, run in the child before a `Query`.** It accepts exactly one SELECT. `Exec` stays unrestricted and is for the archive only: PR 4's query and widget paths must call `Query`.
6. **`max_temp_directory_size` is fixed at 4 GB per child** (`Options.MaxTempSize`, no variable; D23 allows no new engine variables). DuckDB's default is 90% of the free disk, the same disk as the SQLite file.
7. **An idle child yields its slot.** A process waiting for a slot touches `<slots>/waiting` every 50 ms. An engine whose child is idle checks that file every second and retires its child when it was touched in the last 2 s. On a split install with `ENGINE_MAX_CHILDREN=1`, the other process then waits about a second instead of up to 3 minutes.
8. **The installer refusal test stays manual** (`make test-install`). PR 2's review listed it among PR 3's entry conditions as "consider CI". It needs docker, and its subject is unrelated to the log, so it waits for a CI change of its own.
9. **No `Files(project, from, to)` yet.** The roadmap lists it, but nothing reads the files in this release. PR 4 adds it with its first reader.

## Review Focus

1. **A crash mid-append** leaves a torn line. It must be gone before any later append or dump. Pinned by Task 4 `TestOpenLogCutsATornLine` and `TestFailedWriteLeavesNoPartialLine`.
2. **A late event for yesterday arriving after the pass dumped yesterday** must become a segment (`<day>.1.parquet`) and later merge into the month without duplicates. Pinned by Task 6 `TestLateLogBecomesASegmentAndMerges`.
3. **A crash after a merge's rename, before its inputs are deleted,** must not double-count after the next pass. Pinned by Task 6 `TestMergeIncludesAnExistingMonthFile`.
4. **The day file's row count equals SQLite's for the same day** (the roadmap's "done when"), including retried batches and an approved form submission. Pinned by Task 8 `TestDailyPassDumpsWhatSQLiteHolds`.
5. **Widget SQL that tries to write** (`COPY`, `CREATE`, `ATTACH`, a `SELECT …; COPY …` string) must be refused before anything runs, with no file written. Pinned by Task 1 `TestChildQueriesAreReadOnly`.

```go
// readOnly lets one SELECT through (DESCRIBE, SHOW, SUMMARIZE, FROM and
// VALUES parse as one) and nothing else: DuckDB's allowed directory is
// read-write, so a query must not COPY, CREATE or ATTACH. It parses with
// json_serialize_sql, which runs nothing; preparing would run every
// statement of a multi-statement string but the last.
func readOnly(ctx context.Context, db *sql.DB, q string) error {
	var out string
	if err := db.QueryRowContext(ctx, "SELECT json_serialize_sql(CAST(? AS VARCHAR))::VARCHAR", q).Scan(&out); err != nil {
		return fmt.Errorf("engine: %w", err)
	}
	var parsed struct {
		Error      bool              `json:"error"`
		Type       string            `json:"error_type"`
		Message    string            `json:"error_message"`
		Statements []json.RawMessage `json:"statements"`
	}
	if err := json.Unmarshal([]byte(out), &parsed); err != nil {
		return fmt.Errorf("engine: %w", err)
	}
	if parsed.Error && parsed.Type == "parser" {
		return errors.New("engine: " + parsed.Message)
	}
	if parsed.Error || len(parsed.Statements) != 1 {
		return errors.New("engine: a query must be one SELECT statement")
	}
	return nil
}
```

```go
// waitingFile is touched by a process waiting for a slot; an engine whose
// child is idle sees it and retires the child (yieldPoll).
const waitingFile = "waiting"

// waiting reports whether some process waited for a slot in the last 2 s.
func waiting(dir string) bool {
	st, err := os.Stat(filepath.Join(dir, waitingFile))
	return err == nil && time.Since(st.ModTime()) < 2*time.Second
}

// markWaiting records that this process is waiting for a slot.
func markWaiting(dir string) {
	p := filepath.Join(dir, waitingFile)
	now := time.Now()
	if os.Chtimes(p, now, now) != nil {
		if f, err := os.OpenFile(p, os.O_CREATE|os.O_WRONLY, 0o600); err == nil {
			f.Close()
		}
	}
}
```

```go
// armIdle (e.mu held) schedules the idle check: the child retires at
// deadline, or as soon as another engine waits for a slot.
func (e *Engine) armIdle(c *child, deadline time.Time) {
	wait := time.Until(deadline)
	if wait > yieldPoll {
		wait = yieldPoll
	}
	c.idle = time.AfterFunc(wait, func() {
		if time.Now().Before(deadline) && !waiting(e.o.SlotDir) {
			e.mu.Lock()
			if e.child == c && c.busy == 0 && c.idle != nil {
				e.armIdle(c, deadline)
			}
			e.mu.Unlock()
			return
		}
		e.retire(c)
	})
}
```

`retire` is unchanged: it backs off when a request arrived meanwhile. `start` already stops `c.idle` and sets it to nil, which ends the re-arming.

`internal/archive/log.go`:

```go
package archive

import (
	"bytes"
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strconv"
	"strings"
	"sync"
	"time"

	"github.com/dmtrkzntsv/twillingate/internal/store"
)

// lineVersion is the log line's format (the v field).
const lineVersion = 1

// recentIDs is how long an id that reached the log keeps a repeat out of it:
// the pipeline's retries and an SDK's prompt ones. A later repeat is the
// dump's to drop (DISTINCT ON id).
const recentIDs = 10 * time.Minute

const tsFormat = "2006-01-02T15:04:05Z"

// Log appends events to raw/<project>/<day>.log, one descriptor per open
// log, fsynced once per WriteEvents (the pipeline's flush).
type Log struct {
	dir   string
	mu    sync.Mutex
	files map[logKey]*os.File
	seen  map[string]time.Time
	now   func() time.Time
	// failWrite, when set, replaces the file write (tests).
	failWrite func(f *os.File, b []byte) (int, error)
}

type logKey struct {
	project int64
	day     string
}

// OpenLog opens the log under dir, cutting every open log back to its last
// newline: a line torn by a crash never reaches an append or a dump.
func OpenLog(dir string) (*Log, error) {
	if err := os.MkdirAll(dir, 0o750); err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	logs, err := filepath.Glob(filepath.Join(dir, "*", "*.log"))
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	for _, p := range logs {
		if err := cutTornLine(p); err != nil {
			return nil, err
		}
	}
	return &Log{dir: dir, files: map[logKey]*os.File{}, seen: map[string]time.Time{}, now: time.Now}, nil
}

// cutTornLine truncates path after its last newline.
func cutTornLine(path string) error {
	b, err := os.ReadFile(path)
	if err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	keep := bytes.LastIndexByte(b, '\n') + 1
	if keep == len(b) {
		return nil
	}
	if err := os.Truncate(path, int64(keep)); err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	return nil
}

func (l *Log) Dir() string { return l.dir }

// WriteEvents appends each event not written in the last recentIDs to its
// project and day's log, then fsyncs every log it touched. A write that
// fails is cut back to the file's previous size and its ids are not
// remembered, so the pipeline's retry writes them again.
func (l *Log) WriteEvents(ctx context.Context, evs []store.Event) error {
	l.mu.Lock()
	defer l.mu.Unlock()
	now := l.now()
	for id, at := range l.seen {
		if now.Sub(at) > recentIDs {
			delete(l.seen, id)
		}
	}
	batch := map[logKey]*bytes.Buffer{}
	ids := map[logKey][]string{}
	var order []logKey
	inBatch := map[string]bool{}
	for _, e := range evs {
		if _, ok := l.seen[e.ID]; ok || inBatch[e.ID] {
			continue
		}
		inBatch[e.ID] = true
		b, err := line(e)
		if err != nil {
			return fmt.Errorf("archive: event %s: %w", e.ID, err)
		}
		k := logKey{e.ProjectID, Day(e.TS)}
		if batch[k] == nil {
			batch[k] = &bytes.Buffer{}
			order = append(order, k)
		}
		batch[k].Write(b)
		ids[k] = append(ids[k], e.ID)
	}
	var touched []*os.File
	for _, k := range order {
		f, err := l.file(k)
		if err != nil {
			return err
		}
		if err := l.append(f, batch[k].Bytes()); err != nil {
			return err
		}
		for _, id := range ids[k] {
			l.seen[id] = now
		}
		touched = append(touched, f)
	}
	var errs []error
	for _, f := range touched {
		if err := f.Sync(); err != nil {
			errs = append(errs, fmt.Errorf("archive: %w", err))
		}
	}
	return errors.Join(errs...)
}

// append writes b at the end of f in one write, cutting f back to its
// previous size if the write fails or falls short.
func (l *Log) append(f *os.File, b []byte) error {
	st, err := f.Stat()
	if err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	write := func(f *os.File, b []byte) (int, error) { return f.Write(b) }
	if l.failWrite != nil {
		write = l.failWrite
	}
	n, err := write(f, b)
	if err == nil && n < len(b) {
		err = io.ErrShortWrite
	}
	if err != nil {
		if terr := f.Truncate(st.Size()); terr != nil {
			return fmt.Errorf("archive: %w (and cutting it back: %v)", err, terr)
		}
		return fmt.Errorf("archive: %w", err)
	}
	return nil
}

// file returns the open log for k, opening it O_APPEND.
func (l *Log) file(k logKey) (*os.File, error) {
	if f := l.files[k]; f != nil {
		return f, nil
	}
	dir := filepath.Join(l.dir, strconv.FormatInt(k.project, 10))
	if err := os.MkdirAll(dir, 0o750); err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	f, err := os.OpenFile(filepath.Join(dir, k.day+".log"), os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o640)
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	l.files[k] = f
	return f, nil
}

// Rotate closes the project's log for day and renames it <day>.<n>.closed
// with the next free n, ready for its dump; a later event for the day
// starts a new log. It returns the closed file's path, or "" when the day
// has no log.
func (l *Log) Rotate(project int64, day string) (string, error) {
	l.mu.Lock()
	defer l.mu.Unlock()
	k := logKey{project, day}
	if f := l.files[k]; f != nil {
		delete(l.files, k)
		if err := f.Close(); err != nil {
			return "", fmt.Errorf("archive: %w", err)
		}
	}
	dir := filepath.Join(l.dir, strconv.FormatInt(project, 10))
	src := filepath.Join(dir, day+".log")
	if _, err := os.Stat(src); errors.Is(err, os.ErrNotExist) {
		return "", nil
	}
	for n := 1; ; n++ {
		dst := filepath.Join(dir, day+"."+strconv.Itoa(n)+".closed")
		if _, err := os.Stat(dst); errors.Is(err, os.ErrNotExist) {
			if err := os.Rename(src, dst); err != nil {
				return "", fmt.Errorf("archive: %w", err)
			}
			return dst, nil
		}
	}
}

// Close closes every open log.
func (l *Log) Close() error {
	l.mu.Lock()
	defer l.mu.Unlock()
	var errs []error
	for k, f := range l.files {
		errs = append(errs, f.Close())
		delete(l.files, k)
	}
	return errors.Join(errs...)
}

// line is e as one NDJSON line shaped like its Parquet row (raw-first Q10):
// the events table's column names, attributes flat as attr_<key> (the key
// as stored, unsanitized), empty fields left out, v the format.
func line(e store.Event) ([]byte, error) {
	m := map[string]any{
		"v": lineVersion, "id": e.ID, "project_id": e.ProjectID, "family": string(e.Family),
		"event_name": e.EventName, "ts": e.TS.UTC().Format(tsFormat), "day": Day(e.TS),
	}
	if !e.ReceivedAt.IsZero() {
		m["received_at"] = e.ReceivedAt.UTC().Format(tsFormat)
	}
	for k, v := range map[string]string{
		"kind": e.Kind, "actor_id": e.ActorID, "actor_kind": e.ActorKind, "user_id": e.UserID,
		"group_id": e.GroupID, "session_id": e.SessionID, "host": e.Host, "path": e.Path,
		"referrer_source": e.ReferrerSource, "utm_source": e.UTMSource, "utm_medium": e.UTMMedium,
		"utm_campaign": e.UTMCampaign, "platform": e.Platform, "os": e.OS, "os_version": e.OSVersion,
		"os_name": e.OSName, "browser": e.Browser, "browser_version": e.BrowserVersion,
		"browser_locale": e.BrowserLocale, "app_version": e.AppVersion, "app_locale": e.AppLocale,
		"device": e.Device, "device_model": e.DeviceModel, "country": e.Country, "measure": e.Measure,
	} {
		if v != "" {
			m[k] = v
		}
	}
	if e.DisplayWidth != 0 {
		m["display_width"] = e.DisplayWidth
	}
	if e.DisplayHeight != 0 {
		m["display_height"] = e.DisplayHeight
	}
	switch e.Consent {
	case store.ConsentGiven:
		m["consent"] = 1
	case store.ConsentNone:
		m["consent"] = 0
	}
	if e.Value != nil {
		m["value"] = *e.Value
	}
	rate := e.SampleRate
	if rate == 0 {
		rate = 1
	}
	m["sample_rate"] = rate
	for k, v := range e.Attributes {
		if !strings.HasPrefix(k, "$") {
			m["attr_"+k] = v
		}
	}
	b, err := json.Marshal(m)
	if err != nil {
		return nil, err
	}
	return append(b, '\n'), nil
}
```

```go
import (
```

```go
// Execer runs a statement in the engine (engine.Engine.Exec): the archive
// is the one caller allowed to write through it.
type Execer interface {
	Exec(ctx context.Context, sql string) error
}

// Archive maintains the files the Log fills.
type Archive struct {
	log    *Log
	eng    Execer
	logger *slog.Logger
}

func New(log *Log, eng Execer, logger *slog.Logger) *Archive {
	return &Archive{log: log, eng: eng, logger: logger}
}

var (
	logName     = regexp.MustCompile(`^(\d{4}-\d{2}-\d{2})\.log$`)
	closedName  = regexp.MustCompile(`^(\d{4}-\d{2}-\d{2})\.\d+\.closed$`)
	dayFileName = regexp.MustCompile(`^(\d{4}-\d{2}-\d{2})(\.\d+)?\.parquet$`)
	monthName   = regexp.MustCompile(`^(\d{4}-\d{2})\.parquet$`)
)

// Maintain runs the file side of the daily pass for every project
// directory: rotate and dump the logs of days before today, merge every
// month whose last day is past the late window, delete months entirely
// older than retentionDays. A project's failure is logged and the next
// one goes on (the daily pass's rule); only failing to list the projects
// is returned.
func (a *Archive) Maintain(ctx context.Context, today civil.Date, lateDays, retentionDays int) error {
	entries, err := os.ReadDir(a.log.Dir())
	if err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	for _, e := range entries {
		project, err := strconv.ParseInt(e.Name(), 10, 64)
		if err != nil || !e.IsDir() {
			continue
		}
		if err := a.maintainProject(ctx, project, today, lateDays, retentionDays); err != nil {
			a.logger.Error("archive: maintenance", "project", project, "error", err)
		}
		if ctx.Err() != nil {
			return ctx.Err()
		}
	}
	return nil
}

func (a *Archive) maintainProject(ctx context.Context, project int64, today civil.Date, lateDays, retentionDays int) error {
	dir := filepath.Join(a.log.Dir(), strconv.FormatInt(project, 10))
	names, err := list(dir)
	if err != nil {
		return err
	}
	// 1. Close every log of a day before today.
	for _, n := range names {
		if m := logName.FindStringSubmatch(n); m != nil && m[1] < today.String() {
			if _, err := a.log.Rotate(project, m[1]); err != nil {
				return err
			}
		}
	}
	// 2. Dump every closed log, the ones a crashed pass left included.
	if names, err = list(dir); err != nil {
		return err
	}
	for _, n := range names {
		if m := closedName.FindStringSubmatch(n); m != nil {
			if err := a.dump(ctx, dir, n, m[1]); err != nil {
				return err
			}
		}
	}
	// 3. Merge every final month; 4. delete the expired ones.
	if names, err = list(dir); err != nil {
		return err
	}
	// A month goes once its last day is at least retentionDays old (D5:
	// entirely older than the window).
	keep := today.AddDays(-retentionDays)
	for _, month := range months(names) {
		last := lastDay(month)
		if !keep.Before(last) {
			if err := removeMonth(dir, names, month); err != nil {
				return err
			}
			continue
		}
		if last.AddDays(lateDays).Before(today) && !open(names, month) {
			if err := a.merge(ctx, dir, names, month); err != nil {
				return err
			}
		}
	}
	return nil
}

// dump writes a closed log as the day's file, or as its next segment when
// the day file exists, then deletes the log. DISTINCT ON (id) drops what
// the recent-ids window let through; DuckDB infers the columns from every
// line (raw-first D2).
func (a *Archive) dump(ctx context.Context, dir, closed, day string) error {
	src := filepath.Join(dir, closed)
	if st, err := os.Stat(src); err == nil && st.Size() == 0 {
		return os.Remove(src)
	}
	out := filepath.Join(dir, day+".parquet")
	for n := 1; exists(out); n++ {
		out = filepath.Join(dir, day+"."+strconv.Itoa(n)+".parquet")
	}
	q := "COPY (SELECT DISTINCT ON (id) * FROM read_ndjson(" + quote(src) + ", sample_size=-1) ORDER BY family, ts) TO "
	if err := a.write(ctx, q, out); err != nil {
		return err
	}
	return os.Remove(src)
}

// merge writes every day file and segment of month, with the month file
// if a crashed merge left one, as the month file, then deletes the days.
func (a *Archive) merge(ctx context.Context, dir string, names []string, month string) error {
	var inputs, days []string
	for _, n := range names {
		if m := dayFileName.FindStringSubmatch(n); m != nil && strings.HasPrefix(m[1], month+"-") {
			inputs = append(inputs, quote(filepath.Join(dir, n)))
			days = append(days, n)
		}
	}
	if len(days) == 0 {
		return nil
	}
	if exists(filepath.Join(dir, month+".parquet")) {
		inputs = append(inputs, quote(filepath.Join(dir, month+".parquet")))
	}
	q := "COPY (SELECT DISTINCT ON (id) * FROM read_parquet([" + strings.Join(inputs, ", ") + "], union_by_name=true) ORDER BY family, ts) TO "
	if err := a.write(ctx, q, filepath.Join(dir, month+".parquet")); err != nil {
		return err
	}
	for _, n := range days {
		if err := os.Remove(filepath.Join(dir, n)); err != nil {
			return fmt.Errorf("archive: %w", err)
		}
	}
	return nil
}

// write runs copyTo (a COPY … TO, missing its target) into out.tmp, fsyncs
// it, renames it over out and fsyncs the directory: a reader sees the old
// file or the whole new one, and a crash leaves at most a .tmp.
func (a *Archive) write(ctx context.Context, copyTo, out string) error {
	tmp := out + ".tmp"
	os.Remove(tmp)
	if err := a.eng.Exec(ctx, copyTo+quote(tmp)+" (FORMAT parquet, COMPRESSION zstd)"); err != nil {
		return fmt.Errorf("archive: %s: %w", filepath.Base(out), err)
	}
	if err := syncFile(tmp); err != nil {
		return err
	}
	if err := os.Rename(tmp, out); err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	return syncFile(filepath.Dir(out))
}

// RemoveProject deletes a purged project's directory (raw-first D6). Its
// open logs are closed first; an event for it still in the pipeline
// recreates the directory, and the next purge pass removes it.
func (a *Archive) RemoveProject(id int64) error {
	a.log.forget(id)
	if err := os.RemoveAll(filepath.Join(a.log.Dir(), strconv.FormatInt(id, 10))); err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	return nil
}

func list(dir string) ([]string, error) {
	entries, err := os.ReadDir(dir)
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	var names []string
	for _, e := range entries {
		names = append(names, e.Name())
	}
	return names, nil
}

// months lists the months any day or month file of names belongs to.
func months(names []string) []string {
	set := map[string]bool{}
	for _, n := range names {
		if m := dayFileName.FindStringSubmatch(n); m != nil {
			set[m[1][:7]] = true
		} else if m := monthName.FindStringSubmatch(n); m != nil {
			set[m[1]] = true
		}
	}
	var out []string
	for m := range set {
		out = append(out, m)
	}
	sort.Strings(out)
	return out
}

func lastDay(month string) civil.Date {
	first, _ := time.Parse("2006-01", month)
	return civil.DateOf(first.AddDate(0, 1, -1))
}

// open reports whether month still has a log or a closed log (a dump that
// failed): it is not final yet.
func open(names []string, month string) bool {
	for _, n := range names {
		if (logName.MatchString(n) || closedName.MatchString(n)) && strings.HasPrefix(n, month+"-") {
			return true
		}
	}
	return false
}

func removeMonth(dir string, names []string, month string) error {
	for _, n := range names {
		if strings.HasPrefix(n, month) {
			if err := os.Remove(filepath.Join(dir, n)); err != nil && !errors.Is(err, os.ErrNotExist) {
				return fmt.Errorf("archive: %w", err)
			}
		}
	}
	return nil
}

func exists(path string) bool {
	_, err := os.Stat(path)
	return err == nil
}

func syncFile(path string) error {
	f, err := os.Open(path)
	if err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	defer f.Close()
	if err := f.Sync(); err != nil {
		return fmt.Errorf("archive: %w", err)
	}
	return nil
}

// quote is path as a SQL string literal.
func quote(path string) string { return "'" + strings.ReplaceAll(path, "'", "''") + "'" }
```

```go
func splitLines(b []byte) [][]byte {
	var out [][]byte
	for len(b) > 0 {
		i := 0
```
