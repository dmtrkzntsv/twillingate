# Form Attribution From the Files Implementation Plan (PR 5b)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A form submission's source is found after it arrives, by a job that reads the event files. The source is the last non-direct visit of the submitter within `FORMS_ATTRIBUTION_DAYS` (default 7). The submitter includes the install ids `aliases` pairs with the user. `SessionAt` and its SQLite read of the raw views go. With consent, an anonymous SDK instance keeps a pseudonymous visitor id, so its visits connect across days.

**Architecture:**
- **At arrival,** the form handler writes the submission with a *pending event*: the `$form_submit` event as far as the request knows it (id, actor, page, country, and any referrer or UTMs the client sent). Whether to write the event is decided at arrival, by the form being approved.
- **Every minute,** the jobs runner of the ingest process takes the pending submissions older than a minute. It asks `archive.Reader.Attribute` about all of them in one engine query over `sessions`, `views` and `aliases`. For each, it writes the attribution, plus the event if one is due, to SQLite and the event to the archive log.
- **The SDK** sends its persisted visitor id as `$install_id` whenever the instance has consent, anonymous or identified. Identified mode still alone sends `$user_id`, `$user_name` and a declared install id.

**Tech Stack:** Go 1.25, DuckDB through `internal/engine` (the child), the PR 4/5a reader (`internal/archive`), modernc SQLite (migration 041), TypeScript SDK (vitest/jsdom, esbuild).

**Spec:** `docs/superpowers/specs/2026-10-12-raw-first-design.md`, D22, revised (below). D16 to D18 provide the tables it reads. Roadmap: `docs/superpowers/plans/2026-10-12-raw-first-roadmap.md`, PR 5b. Stacked on PR 5a (`feat/raw-derived`, draft PR #182), whose `sessions` and `aliases` tables this reads.

## How D22 changed (decided with the user, 2026-10-14)

D22 had the SDK send the visit and the server look nothing up. Planning found that the default instance (anonymous, no consent) keeps nothing across page loads, and a plain HTML form has no SDK at all. Both would have lost the attribution `SessionAt` gives them today.

A first revision kept visits in ingest's memory. The user replaced it with a job that looks the source up in the files after the submission arrives, because:

- **Configurable lookback.** The source can be the last non-direct visit within N days, not only the current visit's landing. An ad click on Monday followed by a direct return on Friday counts as the ad.
- **Robustness.** Restarts and crashes lose nothing, since the queue is in SQLite. Views still in the SDK's queue or the pipeline buffer when the form arrives are on file a minute later.
- **One source of truth.** It reads the files (D1); nothing is kept in memory.

**The limit:** an actor the files can follow across days needs a stable id. Anonymous actors without consent are a connection hash under a salt that rotates at midnight UTC (by design), so for them the lookback ends at midnight. The user's ruling: with consent, an anonymous instance is pseudonymous. It persists a visitor id and sends it as `$install_id`, so its visits connect; it still never says who the visitor is.

**Roadmap correction kept:** the client declares the environment, and ingest only validates it; the User-Agent is never parsed. The submission's event takes the environment of the actor's newest view.

## Decisions this plan takes (review them)

1. **Attribution model: last non-direct.** The source is the referrer and UTMs of the newest session that had any. A session counts if it started within `FORMS_ATTRIBUTION_DAYS` days before the submission, up to and including its arrival. No such session means direct (`{}`). Sessions are 5a's `sessions` table, so a session's source is its first view's.
2. **The submitter is three kinds of actor:**
   - the submission's actor;
   - the `$install_id` it was sent with;
   - for a `user` actor, every install id `aliases` pairs with that user.

   So a visitor who lands from an ad as an install, then signs in and submits as the user, keeps the ad as the source.
3. **The rest of the event comes from the newest view** in the same window: kind, group, session id, environment and consent. With no view, these stay empty, as today when `SessionAt` found no session.
4. **What the client sends wins.** When a submission sends a referrer or a UTM (`$referrer`, `$utm_*`, accepted from now on, also as hidden fields of a plain form), those four are its source and the lookup gives none of them. A sent referrer from the form's own host cleans to empty, and then the lookup's source applies.
5. **`FORMS_ATTRIBUTION_DAYS`:** default 7, at least 1, at most `RETENTION_DAYS`. A change applies to submissions not yet attributed.
6. **Timing:**
   - A submission waits at least a minute (`attributionDelay`), so the views sent just before it are on file: the SDK flushes every 10 seconds and the pipeline every 5.
   - The job runs on the jobs runner's minute tick, in the process that ingests. A console-only process has no archive and runs none.
   - It asks about at most 100 submissions per tick.
   - When the lookup fails, it retries each minute. After an hour (`attributionGiveUp`), the submission is attributed with what the client sent alone, so a broken engine costs attribution, never the conversion.
7. **The `$form_submit` event is written by the job,** with the submission's id, `ts` as its arrival, and the attribution. It is written to SQLite (`insertEvents`, in the same transaction that clears the pending row) and to the archive log. It is late by a minute or more, well inside `INGEST_LATE_DAYS`. A submission deleted before the job runs gets no event (the job's `UPDATE … WHERE pending_event IS NOT NULL` finds no row).
8. **A submission's `attribution` is `NULL` (shown as `{}`) until the job runs.** Existing submissions are already attributed: migration 041 only adds nullable columns, and NULL means done.
9. **Anonymous with consent sends `$install_id`.** This is a breaking change for sites that run anonymous tags with consent:
   - they start sending a persistent pseudonymous id;
   - `project receives ids` is logged for them;
   - their multi-day unique visitors drop, since a returning visitor is one actor, not one per day.

   `installId(id)` stays identified-only, so an anonymous instance never sends a declared id. The SDK commit is `feat(sdk)!`.
10. **No rules on the lookup.** Renames, merges and blocks never apply to views, sessions or aliases (5a, decision 9). The reader is still handed the full rule set, because its tables are shared (`Reader.Query`'s contract).

```go
package archive

import (
	"context"
	"fmt"
	"strconv"
	"strings"
	"time"

	"github.com/dmtrkzntsv/twillingate/internal/store"
)

// Lookup asks where one form submission came from (Attribute).
type Lookup struct {
	ProjectID          int64
	ID                 string    // the submission's id
	ActorKind, ActorID string    // its actor
	InstallID          string    // the $install_id it was sent with, "" if none
	At                 time.Time // its arrival
}

// Found is what the files say of one Lookup: Source holds the referrer
// and UTMs of the newest session with any (zero: direct), Newest the
// newest view's kind, group, session id, environment and consent (zero:
// no view).
type Found struct {
	ProjectID int64
	ID        string
	Source    store.Event
	Newest    store.Event
}

// sourceColumns and newestColumns are what Found reads off a session and
// a view, in the order attributionSQL selects them.
var (
	sourceColumns = []string{"referrer_source", "utm_source", "utm_medium", "utm_campaign"}
	newestColumns = []string{"kind", "group_id", "session_id", "platform", "os", "os_version", "os_name",
		"browser", "browser_version", "browser_locale", "app_version", "app_locale", "device", "device_model",
		"display_width", "display_height", "consent"}
)

// Attribute answers ls in one query over the tables Query reads (so rules
// is the full rule set, as for Query). For each lookup it reads the
// sessions and views from `days` days before At up to At, of the
// lookup's actor, of the install id it was sent with and, for a user, of
// every install id aliases pairs with the user. One Found per lookup, in
// no particular order.
func (r *Reader) Attribute(ctx context.Context, ls []Lookup, days int, rules Rules) ([]Found, error) {
	if len(ls) == 0 {
		return nil, nil
	}
	res, err := r.Query(ctx, attributionSQL(ls, days), 0, rules)
	if err != nil {
		return nil, err
	}
	out := make([]Found, 0, len(res.Rows))
	for _, row := range res.Rows {
		str := func(i int) string {
			s, _ := row[i].(string)
			return s
		}
		project, err := strconv.ParseInt(str(0), 10, 64)
		if err != nil {
			return nil, fmt.Errorf("archive: attribution project %v: %w", row[0], err)
		}
		f := Found{ProjectID: project, ID: str(1)}
		f.Source = store.Event{ReferrerSource: str(2), UTMSource: str(3), UTMMedium: str(4), UTMCampaign: str(5)}
		n := 6 // the first of newestColumns
		f.Newest = store.Event{Kind: str(n), GroupID: str(n + 1), SessionID: str(n + 2), Platform: str(n + 3),
			OS: str(n + 4), OSVersion: str(n + 5), OSName: str(n + 6), Browser: str(n + 7),
			BrowserVersion: str(n + 8), BrowserLocale: str(n + 9), AppVersion: str(n + 10), AppLocale: str(n + 11),
			Device: str(n + 12), DeviceModel: str(n + 13)}
		f.Newest.DisplayWidth, _ = strconv.Atoi(str(n + 14))
		f.Newest.DisplayHeight, _ = strconv.Atoi(str(n + 15))
		switch str(n + 16) {
		case "1":
			f.Newest.Consent = store.ConsentGiven
		case "0":
			f.Newest.Consent = store.ConsentNone
		}
		out = append(out, f)
	}
	return out, nil
}

// attributionSQL is Attribute's query. Every value from a lookup is a
// literal; every column it returns is VARCHAR, NULL when nothing matched.
func attributionSQL(ls []Lookup, days int) string {
	rows := make([]string, len(ls))
	for i, l := range ls {
		rows[i] = fmt.Sprintf("(%d, %s, %s, %s, %s, CAST(%s AS TIMESTAMP))", l.ProjectID, literal(l.ID),
			literal(l.ActorKind), literal(l.ActorID), literal(l.InstallID), literal(l.At.UTC().Format("2006-01-02 15:04:05")))
	}
	window := fmt.Sprintf("INTERVAL %d DAY", days)
	as := func(alias string, cols []string) string {
		out := make([]string, len(cols))
		for i, c := range cols {
			out[i] = fmt.Sprintf("CAST(%s.%s AS VARCHAR) AS %s", alias, c, c)
		}
		return strings.Join(out, ", ")
	}
	pick := func(alias string, cols []string) string {
		out := make([]string, len(cols))
		for i, c := range cols {
			out[i] = alias + "." + c
		}
		return strings.Join(out, ", ")
	}
	hasSource := make([]string, len(sourceColumns))
	for i, c := range sourceColumns {
		hasSource[i] = "coalesce(s." + c + ", '') <> ''"
	}
	install, user := literal(store.ActorInstall), literal(store.ActorUser)
	return `WITH l(project_id, id, actor_kind, actor_id, install_id, at) AS (VALUES ` + strings.Join(rows, ", ") + `),
who AS (
  SELECT project_id, id, actor_kind, actor_id, at FROM l
  UNION SELECT project_id, id, ` + install + `, install_id, at FROM l WHERE install_id <> ''
  UNION SELECT l.project_id, l.id, ` + install + `, a.install_id, l.at FROM l
    JOIN aliases a ON a.project_id = l.project_id AND a.user_id = l.actor_id
    WHERE l.actor_kind = ` + user + `
),
src AS (
  SELECT w.project_id, w.id, ` + as("s", sourceColumns) + `,
    row_number() OVER (PARTITION BY w.project_id, w.id ORDER BY s.started_at DESC, s.actor_kind, s.actor_id) AS n
  FROM who w JOIN sessions s ON s.project_id = w.project_id
    AND s.actor_kind = w.actor_kind AND s.actor_id = w.actor_id
    AND s.started_at <= w.at AND s.started_at >= w.at - ` + window + `
  WHERE ` + strings.Join(hasSource, " OR ") + `
),
newest AS (
  SELECT w.project_id, w.id, ` + as("v", newestColumns) + `,
    row_number() OVER (PARTITION BY w.project_id, w.id ORDER BY v.ts DESC, v.id DESC) AS n
  FROM who w JOIN views v ON v.project_id = w.project_id
    AND v.actor_kind = w.actor_kind AND v.actor_id = w.actor_id
    AND v.ts <= w.at AND v.ts >= w.at - ` + window + `
)
SELECT CAST(l.project_id AS VARCHAR), l.id, ` + pick("src", sourceColumns) + `, ` + pick("newest", newestColumns) + `
FROM l
LEFT JOIN src ON src.project_id = l.project_id AND src.id = l.id AND src.n = 1
LEFT JOIN newest ON newest.project_id = l.project_id AND newest.id = l.id AND newest.n = 1`
}
```

// PendingSubmissions lists up to limit submissions received at or before
// `before` and not yet attributed, oldest first.
func (d *DB) PendingSubmissions(ctx context.Context, before time.Time, limit int) ([]store.PendingSubmission, error) {
	rows, err := d.db.QueryContext(ctx, `SELECT project_id, id, received_at, pending_event, pending_write
		FROM submissions WHERE pending_event IS NOT NULL AND received_at <= ?
		ORDER BY received_at, project_id, id LIMIT ?`, fmtTime(before), limit)
	if err != nil {
		return nil, err
	}
	defer rows.Close()
	var out []store.PendingSubmission
	for rows.Next() {
		var p store.PendingSubmission
		var received, ev string
		var write int64
		if err := rows.Scan(&p.ProjectID, &p.ID, &received, &ev, &write); err != nil {
			return nil, err
		}
		if p.ReceivedAt, err = time.Parse(tsFormat, received); err != nil {
			return nil, fmt.Errorf("submission %s received_at %q: %w", p.ID, received, err)
		}
		if err := json.Unmarshal([]byte(ev), &p.Event); err != nil {
			return nil, fmt.Errorf("submission %s pending event: %w", p.ID, err)
		}
		p.WriteEvent = write == 1
		out = append(out, p)
	}
	return out, rows.Err()
}

		UTMMedium: ev.UTMMedium, UTMCampaign: ev.UTMCampaign}); a != (store.Attribution{}) {

		if err != nil {
			return false, err
		}
		attribution = string(b)
	}

package jobs

import (
	"context"
	"strconv"
	"time"

	"github.com/dmtrkzntsv/twillingate/internal/archive"
	"github.com/dmtrkzntsv/twillingate/internal/store"

// Attributor finds where submissions came from in the event files
// (*archive.Reader).
type Attributor interface {
	Attribute(ctx context.Context, ls []archive.Lookup, days int, rules archive.Rules) ([]archive.Found, error)
}

// EventLog appends events to the archive log (*archive.Log): a
// submission's event goes to SQLite and the files alike.
type EventLog interface {
	WriteEvents(ctx context.Context, evs []store.Event) error
}

// attributionDelay is how old a submission is before its lookup, so the
// views sent just before it are on file: the SDK flushes every 10
// seconds, the pipeline every 5.
const attributionDelay = time.Minute

// attributionGiveUp is how long a submission waits for a lookup that
// works: past it, it is attributed with what its client sent alone, so a
// broken engine costs attribution, never the conversion.
const attributionGiveUp = time.Hour

// attributionBatch bounds the submissions one lookup asks about; the
// rest wait for the next minute.
const attributionBatch = 100

// WithAttribution makes the runner attribute form submissions each
// minute, looking them up through a and writing their events to log too.
// Only a process that ingests has both.
func (r *Runner) WithAttribution(a Attributor, log EventLog) *Runner {
	r.attributor, r.eventLog = a, log
	return r
}

// attributeSubmissions attributes the submissions at least
// attributionDelay old: one lookup for all of them, one transaction each,
// then the written events to the log. A failed lookup is retried the next
// minute; a submission past attributionGiveUp is attributed without it.
func (r *Runner) attributeSubmissions(ctx context.Context) {
	if r.attributor == nil {
		return
	}
	now := r.now().UTC()
	pending, err := r.store.PendingSubmissions(ctx, now.Add(-attributionDelay), attributionBatch)
	if err != nil {
		r.logger.Error("form attribution: pending submissions", "error", err)
		return
	}
	if len(pending) == 0 {
		return
	}
	ls := make([]archive.Lookup, len(pending))
	for i, p := range pending {
		ls[i] = archive.Lookup{ProjectID: p.ProjectID, ID: p.ID, ActorKind: p.Event.ActorKind,
			ActorID: p.Event.ActorID, InstallID: p.Event.InstallID, At: p.ReceivedAt}
	}
	events, attrs := r.reg.Snapshot(ctx).RuleLists()
	found, err := r.attributor.Attribute(ctx, ls, r.cfg.Forms.AttributionDays, archive.Rules{Events: events, Attributes: attrs})
	if err != nil {
		r.logger.Warn("form attribution: lookup failed, retrying next minute", "submissions", len(pending), "error", err)
	}
	key := func(project int64, id string) string { return strconv.FormatInt(project, 10) + "/" + id }
	byKey := make(map[string]archive.Found, len(found))
	for _, f := range found {
		byKey[key(f.ProjectID, f.ID)] = f
	}
	var written []store.Event
	for _, p := range pending {
		f, ok := byKey[key(p.ProjectID, p.ID)]
		if !ok && now.Sub(p.ReceivedAt) < attributionGiveUp {
			continue
		}
		ev := attributed(p.Event, f)
		wrote, err := r.store.AttributeSubmission(ctx, p, ev)
		if err != nil {
			r.logger.Error("form attribution: write", "project", p.ProjectID, "submission", p.ID, "error", err)
			continue
		}
		if wrote {
			written = append(written, ev)
		}
	}
	if len(written) > 0 && r.eventLog != nil {
		if err := r.eventLog.WriteEvents(ctx, written); err != nil {
			r.logger.Error("form attribution: events not logged", "events", len(written), "error", err)
		}
	}
}

// attributed is a submission's event with what the files found: the
// newest view's kind, group, session id, environment and consent, and,
// unless the client sent a referrer or a UTM itself, the source.
func attributed(ev store.Event, f archive.Found) store.Event {
	n := f.Newest
	ev.Kind, ev.GroupID, ev.SessionID = n.Kind, n.GroupID, n.SessionID
	ev.Platform, ev.OS, ev.OSVersion, ev.OSName = n.Platform, n.OS, n.OSVersion, n.OSName
	ev.Browser, ev.BrowserVersion, ev.BrowserLocale = n.Browser, n.BrowserVersion, n.BrowserLocale
	ev.AppVersion, ev.AppLocale, ev.Device, ev.DeviceModel = n.AppVersion, n.AppLocale, n.Device, n.DeviceModel
	ev.DisplayWidth, ev.DisplayHeight, ev.Consent = n.DisplayWidth, n.DisplayHeight, n.Consent
	if ev.ReferrerSource == "" && ev.UTMSource == "" && ev.UTMMedium == "" && ev.UTMCampaign == "" {
		s := f.Source
		ev.ReferrerSource, ev.UTMSource, ev.UTMMedium, ev.UTMCampaign = s.ReferrerSource, s.UTMSource, s.UTMMedium, s.UTMCampaign
	}
	return ev
}
