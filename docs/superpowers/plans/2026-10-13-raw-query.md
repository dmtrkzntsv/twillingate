# Raw Query Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The `query` tool and `POST /api/query` take `source: "files"` and run one read-only SELECT through DuckDB over every project's event files and open logs, exposed as the tables `events`, `views`, `product` and `measures`, with the project's rules applied on read. `source: "sqlite"` (the default in this release) keeps today's behaviour.

**Architecture:** `internal/archive` gains the reader side: `ListFiles` (what a reader sees of `raw/`, without what an interrupted merge or dump left twice), an incremental scanner of the logs' keys, and `Reader`, which builds the tables inside the engine's child. The open logs are loaded into a table, `_tw_hot`, and the Parquet files are read through a view. The child keeps a signature of the files, the logs' sizes and the rules it built from, and the reader rebuilds only when that signature changes. `internal/api` routes `source: "files"` to the reader through an interface, maps DuckDB's errors to messages a model can act on, and passes the registry's rules. `internal/app` creates the engine in every `serve` process, not only the ingesting one.

**Tech Stack:** Go 1.25, `internal/engine` (DuckDB v1.5.6 in a child process), the PR 3 archive (`internal/archive`), `internal/api`'s tool registration, `internal/manage`'s registry snapshot.

**Spec:** `docs/superpowers/specs/2026-10-12-raw-first-design.md`: D4 (one wide table per project with every attribute), D6 (rules apply when read), D8 (the engine child; logs loaded into a table rather than parsed per query), D10 (targets: a 3-year question under 30 s, a timeline under 1 s), D21 (`query` may scan everything; 30 s timeout; out-of-memory message), D23 (`CONSOLE_QUERY_TIMEOUT` default 30 s), Q1, Q11. Roadmap: `docs/superpowers/plans/2026-10-12-raw-first-roadmap.md`, PR 4. PR 3's plan, `2026-10-12-raw-log.md`, for the file layout, the line format and its decisions 1, 5 and 9.

## Facts this plan rests on (probed 2026-10-13, DuckDB v1.5.6 through the engine child)

- **`read_parquet([...], union_by_name=true)` matches column names case-insensitively.** A file with `attr_Plan` and one with `attr_plan` read as one column, named as the first file spells it. A query may name it in either case.
- **A torn last line** fails `read_json_objects(path, format='newline_delimited')` with `Invalid Input Error: Malformed JSON in file …`. With `ignore_errors=true` the torn line reads as one row whose `json` is NULL. The complete lines read normally.
- **`read_parquet` of an empty list fails:** `IO Error: read_parquet needs at least one file to read`. The reader leaves it out when there are no files.
- **A file that vanished between building a view and querying it** fails the query with `IO Error: No files found that match the pattern "…"`.
- **`UNION ALL BY NAME`** of a typed zero-row `SELECT` (`CAST(NULL AS BIGINT) AS project_id, … WHERE false`), a `read_parquet(…, union_by_name=true)` and an in-memory table gives every column once, at the typed SELECT's type where it has one. Columns the first relation lacks are appended.
- **`Exec` of a multi-statement string runs every statement** (`CREATE OR REPLACE TABLE …; CREATE OR REPLACE VIEW …`).
- **`Query` accepts `DESCRIBE <view>` and `SELECT column_name FROM (DESCRIBE <view>)`.** The read-only guard parses both as one SELECT.
- **`SELECT e.* REPLACE (coalesce(r.to_name, e."attr_Plan") AS "attr_Plan") FROM events e LEFT JOIN r …` works.**
- **Out of memory** fails a query with a message starting `Out of Memory Error: failed to allocate data of size …`. The child survives.
- **A table the child does not have** fails with `Catalog Error: Table with name v_views_daily does not exist!`. The same message comes for `agg_*` and `raw_*`.

## Global Constraints

- **Widgets, system dashboards and every tool other than `query` stay on SQLite** (roadmap PR 4: "widgets still run on SQLite"). `query` with no `source`, or with `source: "sqlite"`, behaves exactly as today.
- **Events still go to SQLite and to the log.** PR 3's layout, line format, dump, merge and retention are unchanged. The dump writes the same files: Task 2 refactors `dumpQuery` without changing its SELECT's rows or columns, and PR 3's `maintain_test.go` must stay green.
- **User SQL reaches the engine only through `engine.Engine.Query`,** which accepts exactly one SELECT. `Exec` stays the archive's (PR 3 decision 5). Only the reader's own statements, built in Go, go through `Exec`.
- **No new environment variable** (D23 allows none for the engine). `CONSOLE_QUERY_TIMEOUT`'s default rises from 10 s to 30 s (D21, D23). `CONSOLE_QUERY_ROWS_MAX` caps the rows.

## Decisions this plan takes (review them)

1. **`query` defaults to `sqlite` in this release, and `source: "files"` is opt-in.** The roadmap says `query` "runs on the engine". But the files hold only the events received since the release that began writing them, while SQLite holds the raw window and the aggregates until PR 5 migrates raw rows (D19).
   - Switching the default now would hide that history from every agent for a release, and break every `query` that names a `v_*` view.
   - PR 5 flips the default, when widgets change dialect too, so users meet one breaking day, not two.
   - A files query that names a SQLite table is told to pass `source: "sqlite"`.
2. **Columns keep the key as stored: `attr_<key>`, no sanitizing.** This departs from D4's "sanitizing and collisions follow `flatview.go`".
   - `flatview.go`'s alias is lossy (`plan!` and `plan` both become `attr_plan`). Its `_2` suffixes depend on which keys exist, so a column's name could change when another project sends a new key.
   - DuckDB can name any column in double quotes, so nothing needs a lossy alias. For the usual keys (`[A-Za-z0-9_]`) the name is the one `v_events_flat` uses.
   - Keys equal but for case read as one column across files (Facts). Within one day's file they stay apart as PR 3's `_<n>` suffix (`attr_plan_1`), the gap PR 3 recorded. It stays documented, not fixed: no prod key collides that way, and fixing it would mean rewriting files.
3. **One install-wide `events` over every project,** as today's `query` reads every project through `project_id`. Per-project scoping (Q1: "a widget sees its own project, scoped by the file list") comes with PR 5's widget path, which is where it is needed.
4. **The tables are built on demand, not once at spawn.** D8 says the child loads the open log "once at spawn". But a child lives on while requests keep coming, so a spawn-time load would go stale.
   - Before each query, the reader lists `raw/` and builds a signature: every file's name, size and modification time, plus the rules.
   - It compares that with the signature the child recorded in `_tw_state`, and rebuilds when they differ.
   - The logs are loaded into `_tw_hot` at each rebuild, so no query parses them. That keeps D8's measured gain (2.5 s to 0.35 s for a 30-day dashboard).
   - A log that grew since the last query costs one reload, about 0.4 s for a cap day.
5. **Rules apply on read to every row,** including rows ingest already wrote under the new name (a no-op for those). Removing a rename therefore brings the old name back for rows written before the rename. In SQLite that rewrite stays where it went. The SQL section documents it.
6. **`CONSOLE_QUERY_TIMEOUT` defaults to 30 s from this release,** for SQLite reads and widgets too (D21, D23). `deploy/UPGRADES.md` says how to keep 10 s.
7. **The child caches Parquet footers** (`SET GLOBAL parquet_metadata_cache = true`, before `lock_configuration`). Every query binds every file of the union, and footers are what binding reads. No file is rewritten in place: a merge replaces the month file by rename, which changes the modification time DuckDB checks.
8. **No `Files(project, from, to)` range listing.** `query` has no range (D21: it "may scan everything"). PR 5's widgets add the range with their first ranged reader. Filters on `project_id`, `day` and `ts` let DuckDB skip row groups by their statistics.
9. **Every `serve` process creates the engine,** a console-only one included. A child starts only on the first request, so a process that never needs one runs none.
10. **NULL reads as `""` in `query`'s rows, for files as for SQLite** (`tableOut` is a matrix of strings). An attribute column is NULL wherever the event did not carry the key, so the SQL section tells agents to test `IS NULL` rather than compare with `''`.

## Review Focus

1. **A file the daily pass removes between the listing and the query** (a dump deletes its log, a merge deletes its days) must not fail the query. Expected: the query is retried once on a fresh listing. Pinned by Task 3 `TestReaderRetriesOnceWhenAFileVanished`.
2. **A merge or dump interrupted after its write** leaves both the new file and its inputs. Every row must still count once. Pinned by Task 1 `TestListFilesSkipsWhatAMergeOrDumpLeftBehind` and Task 3 `TestReaderCountsWhatACrashedMergeLeftOnce`.
3. **A torn last line in an open log,** which a split install's console can see while ingest appends, must not fail the query. Expected: the line is absent until it is complete. Pinned by Task 2 `TestLogSelectSkipsATornLineWhenTolerant` and Task 3 `TestReaderSkipsATornLine`.
4. **A fresh install with no `raw/` files** must answer `SELECT count(*) FROM events` with 0, and `DESCRIBE events` with the fixed columns at their types. Pinned by Task 3 `TestReaderOnAnEmptyDirectory`.
5. **A rule made after the files were written** must apply to their rows, a block must hide them, and removing the rule must restore them:
   - a rename, a merge into an existing name, a block, or a rename onto a blocked name;
   - an attribute rename or merge (the target's own value first) and an attribute block;
   - attribute rules leave views alone.
   Pinned by Task 3 `TestReaderAppliesRulesOnRead`, and by Task 4 `TestQueryFilesSourcePassesTheRules`, which checks the registry's rules reach the reader.

```go
package archive

import (
	"errors"
	"fmt"
	"os"
	"path/filepath"
	"regexp"
	"strconv"
	"strings"
)

var monthFileName = regexp.MustCompile(`^(\d{4}-\d{2})\.parquet$`)

// Files is what a reader sees of one project's directory: the Parquet
// files that hold its final rows and the logs that hold the rest (open,
// rotated, or claimed by a dump not done yet), each in name order.
type Files struct {
	Parquet []string
	Logs    []string
}

// ListFiles lists raw/ for a reader, by project id, leaving out what the
// daily pass would make it count twice:
//   - a day file or segment once its month's file exists (a merge that
//     stopped before deleting its days left both; the month file holds them);
//   - a claimed log (<target>.dumping) once its target exists (a dump that
//     stopped before deleting its log).
//
// A .tmp file (a write in progress), any other name and a project with
// nothing listed are left out. A missing raw/ lists nothing; a project
// directory that vanishes while listing (a purge) is skipped.
func ListFiles(dir string) (map[int64]Files, error) {
	entries, err := os.ReadDir(dir)
	if errors.Is(err, os.ErrNotExist) {
		return map[int64]Files{}, nil
	}
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	out := map[int64]Files{}
	for _, e := range entries {
		id, err := strconv.ParseInt(e.Name(), 10, 64)
		if err != nil || !e.IsDir() {
			continue
		}
		pdir := filepath.Join(dir, e.Name())
		names, err := list(pdir)
		if errors.Is(err, os.ErrNotExist) {
			continue
		}
		if err != nil {
			return nil, err
		}
		have := map[string]bool{}
		for _, n := range names {
			have[n] = true
		}
		var f Files
		for _, n := range names {
			p := filepath.Join(pdir, n)
			switch {
			case monthFileName.MatchString(n):
				f.Parquet = append(f.Parquet, p)
			case dayFileName.MatchString(n):
				if !have[dayFileName.FindStringSubmatch(n)[1][:7]+".parquet"] {
					f.Parquet = append(f.Parquet, p)
				}
			case logName.MatchString(n), closedName.MatchString(n):
				f.Logs = append(f.Logs, p)
			case dumpingName.MatchString(n):
				if !have[strings.TrimSuffix(n, ".dumping")] {
					f.Logs = append(f.Logs, p)
				}
			}
		}
		if len(f.Parquet)+len(f.Logs) > 0 {
			out[id] = f
		}
	}
	return out, nil
}
```

`list` wraps its error with `%w`, so `errors.Is(err, os.ErrNotExist)` sees a vanished directory.

```go
package archive

import (
	"bytes"
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"os"
	"sync"
)

// keyScanner remembers, per log, the keys of the lines read so far and
// where the first unread line starts, so a reader's rebuild reads only
// what was appended since: a log only grows until it is rotated, and a
// rotated log is a new path.
type keyScanner struct {
	mu   sync.Mutex
	logs map[string]*scannedLog
}

type scannedLog struct {
	info os.FileInfo // the file read, to tell a new file at the same path
	next int64       // offset of the first line not read yet
	keys map[string]bool
}

func newKeyScanner() *keyScanner { return &keyScanner{logs: map[string]*scannedLog{}} }

// keys returns the keys of path's complete lines: up to its last newline,
// so a line ingest is still writing is read on a later call. A file that
// is not the one read before at path (os.SameFile), or is shorter than
// what was read, is read from its start. A line that is not a JSON object
// is skipped: the dump, not a reader, refuses it. The map is the
// scanner's own: callers must not modify it.
func (s *keyScanner) keys(path string) (map[string]bool, error) {
	s.mu.Lock()
	defer s.mu.Unlock()
	f, err := os.Open(path)
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	defer f.Close()
	st, err := f.Stat()
	if err != nil {
		return nil, fmt.Errorf("archive: %w", err)
	}
	sl := s.logs[path]
	if sl == nil || !os.SameFile(sl.info, st) || st.Size() < sl.next {
		sl = &scannedLog{keys: map[string]bool{}}
		s.logs[path] = sl
	}
	sl.info = st
	if st.Size() <= sl.next {
		return sl.keys, nil
	}
	buf := make([]byte, st.Size()-sl.next)
	n, err := f.ReadAt(buf, sl.next)
	if err != nil && !errors.Is(err, io.EOF) {
		return nil, fmt.Errorf("archive: %w", err)
	}
	buf = buf[:n]
	end := bytes.LastIndexByte(buf, '\n') + 1
	for _, line := range bytes.Split(buf[:end], []byte{'\n'}) {
		var m map[string]json.RawMessage
		if len(line) == 0 || json.Unmarshal(line, &m) != nil || m == nil {
			continue
		}
		for k := range m {
			sl.keys[k] = true
		}
	}
	sl.next += int64(end)
	return sl.keys, nil
}

// keep forgets every log but paths: the ones dumped or removed since.
func (s *keyScanner) keep(paths []string) {
	s.mu.Lock()
	defer s.mu.Unlock()
	live := map[string]bool{}
	for _, p := range paths {
		live[p] = true
	}
	for p := range s.logs {
		if !live[p] {
			delete(s.logs, p)
		}
	}
}
```

```go
// for a reader that may meet the torn last line of a log ingest is still
// writing (read_json_objects with ignore_errors reads such a line as a
// NULL object).
func logSelect(path string, cols []column, tolerant bool) string {
	paths := make([]string, len(cols))
	sel := make([]string, len(cols))
	for i, c := range cols {
		paths[i] = c.pointer()
		sel[i] = "CAST(f[" + strconv.Itoa(i+1) + "] AS " + c.typ + ") AS " + c.ident()

	if tolerant {
		src += ", ignore_errors=true"

	firsts := "SELECT min(ordinality) FROM (SELECT json_extract_string(json, '/id') AS id, ordinality FROM " + lines + ") GROUP BY id"
	unique := "SELECT json FROM (SELECT json, ordinality, json_extract_string(json, '/family') AS family, " +
		"CAST(json_extract_string(json, '/ts') AS TIMESTAMP) AS ts FROM " + lines + ") WHERE ordinality IN (" + firsts + ") ORDER BY family, ts"

// columnsOf lists the columns of a log whose lines hold keys: fields,

func columnsOf(keys map[string]bool) []column {
	taken := map[string]bool{}
	var cols []column
	add := func(key, name, typ string) {
		taken[strings.ToLower(name)] = true
		cols = append(cols, column{key, name, typ})
	}
	fixed := map[string]bool{}
	for _, f := range fields {
		add(f.name, f.name, f.typ)
		fixed[f.name] = true
	}
	var rest, later []string
	for k := range keys {
		if !fixed[k] {
			rest = append(rest, k)
		}
	}
	slices.Sort(rest)
	for _, k := range rest {
		if taken[strings.ToLower(visible(k))] {
			later = append(later, k)
			continue
		}
		add(k, visible(k), "VARCHAR")
	}
	for _, k := range later {
		name := visible(k)
		for n := 1; taken[strings.ToLower(name)]; n++ {
			name = visible(k) + "_" + strconv.Itoa(n)
		}
		add(k, name, "VARCHAR")
	}
	return cols
}
```

```go
// deletes its log, a merge its days) fails the attempt; the query is
// retried once, on a fresh listing.
func (r *Reader) Query(ctx context.Context, sql string, maxRows int, rules Rules) (engine.Result, error) {
	res, err := r.query(ctx, sql, maxRows, rules)
	if vanished(err) {
		res, err = r.query(ctx, sql, maxRows, rules)
	}
	return res, err
}

func (r *Reader) query(ctx context.Context, sql string, maxRows int, rules Rules) (engine.Result, error) {
	if err := r.prepare(ctx, rules); err != nil {
		return engine.Result{}, err
	}
	return r.eng.Query(ctx, sql, maxRows)
}

// vanished reports an error naming a file that is gone.
func vanished(err error) bool {
	if errors.Is(err, os.ErrNotExist) {
		return true
	}
	var qe *engine.QueryError
	return errors.As(err, &qe) && (strings.Contains(qe.Msg, "No files found") || strings.Contains(qe.Msg, "No such file"))
}

// prepare builds the tables unless the child holds them built from the
// files and rules as they are now. A child without _tw_state (a new one)
// answers a query error, which means: build.
func (r *Reader) prepare(ctx context.Context, rules Rules) error {
	r.mu.Lock()
	defer r.mu.Unlock()
	files, err := ListFiles(r.dir)
	if err != nil {
		return err
	}
	rules = sortRules(rules)
	sig, err := signature(files, rules)
	if err != nil {
		return err
	}
	res, err := r.eng.Query(ctx, "SELECT sig FROM _tw_state", 1)
	var qe *engine.QueryError
	switch {
	case err == nil && len(res.Rows) == 1 && res.Rows[0][0] == sig:
		return nil
	case err != nil && !errors.As(err, &qe):
		return err
	}
	return r.build(ctx, files, rules, sig)
}

// signature identifies the files (paths, sizes, modification times) and
// the rules the tables are built from: a log that grew, a file the daily
// pass wrote or removed and a rule made since each change it.
func signature(files map[int64]Files, rules Rules) (string, error) {
	h := sha256.New()
	for _, id := range sortedIDs(files) {
		for _, p := range append(slices.Clone(files[id].Parquet), files[id].Logs...) {
			st, err := os.Stat(p)
			if err != nil {
				return "", fmt.Errorf("archive: %w", err)
			}
			fmt.Fprintf(h, "%s\x00%d\x00%d\n", p, st.Size(), st.ModTime().UnixNano())
		}
	}
	fmt.Fprintf(h, "%v\n%v\n", rules.Events, rules.Attributes)
	return hex.EncodeToString(h.Sum(nil)), nil
}

// build loads the logs into _tw_hot, defines _tw_all over the Parquet
// files and _tw_hot, then events (with the rules), views, product and
// measures, and records sig. Every fixed column is there at its type even
// with no file and no log (emptyRow); v, the line format's version, is not.
func (r *Reader) build(ctx context.Context, files map[int64]Files, rules Rules, sig string) error {
	var parquet, logs []string
	for _, id := range sortedIDs(files) {
		parquet = append(parquet, files[id].Parquet...)
		logs = append(logs, files[id].Logs...)
	}
	hot := []string{emptyRow()}
	for _, p := range logs {
		keys, err := r.keys.keys(p)
		if err != nil {
			return err
		}
		hot = append(hot, "SELECT * FROM ("+logSelect(p, columnsOf(keys), true)+")")
	}
	r.keys.keep(logs)
	all := []string{emptyRow(), "SELECT * FROM _tw_hot"}
	if len(parquet) > 0 {
		all = append(all, "SELECT * FROM read_parquet("+sqlList(parquet)+", union_by_name=true)")
	}
	if err := r.eng.Exec(ctx, "CREATE OR REPLACE TABLE _tw_hot AS "+strings.Join(hot, " UNION ALL BY NAME ")+";\n"+
		"CREATE OR REPLACE VIEW _tw_all AS SELECT * EXCLUDE (v) FROM ("+strings.Join(all, " UNION ALL BY NAME ")+")"); err != nil {
		return err
	}
	res, err := r.eng.Query(ctx, "SELECT column_name FROM (DESCRIBE _tw_all)", 0)
	if err != nil {
		return err
	}
	cols := make([]string, len(res.Rows))
	for i, row := range res.Rows {
		cols[i], _ = row[0].(string)
	}
	return r.eng.Exec(ctx, "CREATE OR REPLACE VIEW events AS "+eventsView(cols, rules)+";\n"+
		"CREATE OR REPLACE VIEW views AS SELECT * FROM events WHERE family = 'views';\n"+
		"CREATE OR REPLACE VIEW product AS SELECT * FROM events WHERE family = 'product';\n"+
		"CREATE OR REPLACE VIEW measures AS SELECT * FROM events WHERE family = 'measures';\n"+
		"CREATE OR REPLACE TABLE _tw_state AS SELECT "+quote(sig)+" AS sig")
}

// emptyRow is a SELECT of no rows with every fixed column at its type.
func emptyRow() string {
	cols := make([]string, len(fields))
	for i, f := range fields {
		cols[i] = "CAST(NULL AS " + f.typ + ") AS " + ident(f.name)
	}
	return "SELECT " + strings.Join(cols, ", ") + " WHERE false"
}

// eventsView is the SELECT of the events table: _tw_all, whose columns
// are cols, with the rules applied (raw-first D6), as ingest applies them
// to what it receives:
//   - an event renamed or merged reads under its new name; a blocked one,
//     and one renamed to a blocked name, is left out;
//   - an attribute key renamed or merged reads in its target's column,
//     the target's own value first, then the renamed keys' in key order;
//     the key itself reads NULL, as a blocked key does;
//   - attribute rules cover the project's product and measures events.
//
// A target column no file has yet is added. Column names match
// case-insensitively, as DuckDB's do. rules are sorted (sortRules).
func eventsView(cols []string, rules Rules) string {
	have := map[string]string{} // a column's name, by its lower-case name
	for _, c := range cols {
		have[strings.ToLower(c)] = c
	}
	type nameKey struct {
		project int64
		family  store.Family
		name    string
	}
	blocked := map[nameKey]bool{}
	for _, r := range rules.Events {
		if r.Action == store.EventRuleBlock {
			blocked[nameKey{r.ProjectID, r.Family, r.Name}] = true
		}
	}
	var renames, drops []string
	for _, r := range rules.Events {
		cond := fmt.Sprintf("project_id = %d AND family = %s AND event_name = %s", r.ProjectID, quote(string(r.Family)), quote(r.Name))
		if r.Action == store.EventRuleBlock || blocked[nameKey{r.ProjectID, r.Family, r.To}] {
			drops = append(drops, "("+cond+")")
		} else {
			renames = append(renames, "WHEN "+cond+" THEN "+quote(r.To))
		}
	}
	var replace, add []string
	if len(renames) > 0 {
		replace = append(replace, "CASE "+strings.Join(renames, " ")+" ELSE event_name END AS event_name")
	}

	type keyKey struct {
		project int64
		key     string
	}
	keyBlocked := map[keyKey]bool{}
	for _, r := range rules.Attributes {
		if r.Action == store.EventRuleBlock {
			keyBlocked[keyKey{r.ProjectID, r.Key}] = true
		}
	}
	scope := func(project int64) string {
		return fmt.Sprintf("project_id = %d AND family IN ('product', 'measures')", project)
	}
	arms := map[string][]string{} // a column's CASE arms, by its lower-case name
	names := map[string]string{}  // the column's name, by its lower-case name
	var order []string
	arm := func(name, when, then string) {
		low := strings.ToLower(name)
		if _, ok := names[low]; !ok {
			names[low] = name
			order = append(order, low)
		}
		arms[low] = append(arms[low], "WHEN "+when+" THEN "+then)
	}
	sources := map[keyKey][]string{} // the columns renamed into a target, in key order
	var targets []keyKey
	for _, r := range rules.Attributes {
		col, ok := have[strings.ToLower("attr_"+r.Key)]
		if !ok {
			continue
		}
		arm(col, scope(r.ProjectID), "NULL")
		if r.Action != store.EventRuleRename || keyBlocked[keyKey{r.ProjectID, r.To}] {
			continue
		}
		t := keyKey{r.ProjectID, r.To}
		if sources[t] == nil {
			targets = append(targets, t)
		}
		sources[t] = append(sources[t], ident(col))
	}
	for _, t := range targets {
		name, vals := "attr_"+t.key, sources[t]
		if col, ok := have[strings.ToLower(name)]; ok {
			name, vals = col, append([]string{ident(col)}, vals...)
		}
		arm(name, scope(t.project), "coalesce("+strings.Join(vals, ", ")+")")
	}
	for _, low := range order {
		name := names[low]
		_, exists := have[low]
		otherwise := "NULL"
		if exists {
			otherwise = ident(name)
		}
		e := "CASE " + strings.Join(arms[low], " ") + " ELSE " + otherwise + " END AS " + ident(name)
		if exists {
			replace = append(replace, e)
		} else {
			add = append(add, e)
		}
	}
	sel := "SELECT *"
	if len(replace) > 0 {
		sel += " REPLACE (" + strings.Join(replace, ", ") + ")"
	}
	for _, e := range add {
		sel += ", " + e
	}
	sel += " FROM _tw_all"
	if len(drops) > 0 {
		sel += " WHERE NOT (" + strings.Join(drops, " OR ") + ")"
	}
	return sel
}

// sortRules orders copies of the rules by project, then family and name
// (events) or key (attributes): the signature and the view must not
// depend on the order the caller listed them in.
func sortRules(r Rules) Rules {
	ev := slices.Clone(r.Events)
	slices.SortFunc(ev, func(a, b store.EventRule) int {
		return cmp.Or(cmp.Compare(a.ProjectID, b.ProjectID), cmp.Compare(a.Family, b.Family), cmp.Compare(a.Name, b.Name))
	})
	at := slices.Clone(r.Attributes)
	slices.SortFunc(at, func(a, b store.AttributeRule) int {
		return cmp.Or(cmp.Compare(a.ProjectID, b.ProjectID), cmp.Compare(a.Key, b.Key))
	})
	return Rules{Events: ev, Attributes: at}
}

func sortedIDs(files map[int64]Files) []int64 {
	ids := make([]int64, 0, len(files))
	for id := range files {
		ids = append(ids, id)
	}
	slices.Sort(ids)
	return ids
}
```

```go
type queryIn struct {
	SQL    string `json:"sql" jsonschema:"a single read-only SELECT or WITH query; for source sqlite read schema://views first, for source files docs://twillingate (Writing SQL against the event files)"`
	Source string `json:"source,omitempty" jsonschema:"optional: sqlite (the default) for the v_* views and agg_* tables; files for the raw events through DuckDB (events, views, product, measures)"`
}

// Files runs SQL over the raw event files (archive.Reader).
type Files interface {
	Query(ctx context.Context, sql string, maxRows int, rules archive.Rules) (engine.Result, error)
}

// runQuery runs in.SQL on SQLite (source sqlite, the default) or on the
// event files (source files). On SQLite it applies the four guard layers
// of endpoint spec §8, all inside readsql.Query: the pool is mode=ro +
// query_only + _defensive; the text is checked and refused (ATTACH; meta
// and SQLite internals; a second statement — readsql.Check tracks paren
// depth and statement boundaries itself, since the driver runs every
// statement it is given and a stray ')' or ';' could otherwise ride a
// trailing statement in on the same call); it is then wrapped as a
// subquery with the row cap in the same clause, so a checked single
// statement that is not itself a query becomes a syntax error; and it
// runs against a deadline. This tool keeps only the messages: readsql's
// sentinel errors map back to the wording this tool has always used.
func (h *host) runQuery(ctx context.Context, in queryIn) (tableOut, error) {
	switch in.Source {
	case "", "sqlite":
	case "files":
		return h.runFilesQuery(ctx, in.SQL)
	default:
		return tableOut{}, invalidf(`source must be "sqlite" or "files", got %q`, in.Source)
	}
	h.logger.Debug("mcp query", "sql", in.SQL) // debug only, never info (spec §8)
	res, err := h.db.Query(ctx, in.SQL)
	if err != nil {
		switch {
		case errors.Is(err, readsql.ErrTimeout):
			return tableOut{}, invalidf("query exceeded %s; narrow the date range or query agg_* tables directly", h.db.Timeout())
		case errors.Is(err, readsql.ErrRefused):
			return tableOut{}, invalidf("%s", strings.TrimPrefix(err.Error(), readsql.ErrRefused.Error()+": "))
		default:
			return tableOut{}, invalidf("SQL error (the query runs wrapped as a subquery; only single SELECT/WITH statements parse): %v", err)
		}
	}
	out := tableOut{Columns: res.Columns, Rows: res.Rows}
	if res.Truncated {
		out.Truncated = true
		out.Note = fmt.Sprintf("truncated to %d rows; results are PARTIAL — add a WHERE or aggregate", h.db.MaxRows())
	}
	return out, nil
}

// runFilesQuery runs sql over the event files in the engine's child,
// under SQLite's row cap and timeout (CONSOLE_QUERY_ROWS_MAX,
// CONSOLE_QUERY_TIMEOUT). The child accepts one SELECT and reaches no
// file outside raw/, which stands in for readsql's guards (raw-first
// D21); the registry's rules reach the tables, which apply them (D6).
func (h *host) runFilesQuery(ctx context.Context, sql string) (tableOut, error) {
	h.logger.Debug("mcp query", "source", "files", "sql", sql) // debug only, never info (spec §8)
	if h.files == nil {
		return tableOut{}, invalidf("the event files cannot be queried by this process")
	}
	ctx, cancel := context.WithTimeout(ctx, h.db.Timeout())
	defer cancel()
	events, attrs := h.reg.Snapshot(ctx).RuleLists()
	res, err := h.files.Query(ctx, sql, h.db.MaxRows(), archive.Rules{Events: events, Attributes: attrs})
	if err != nil {
		return tableOut{}, filesError(err, h.db.Timeout())
	}
	out := tableOut{Columns: res.Columns, Rows: make([][]string, len(res.Rows))}
	for i, row := range res.Rows {
		out.Rows[i] = make([]string, len(row))
		for j, v := range row {
			out.Rows[i][j] = cellText(v)
		}
	}
	if res.Truncated {
		out.Truncated = true
		out.Note = fmt.Sprintf("truncated to %d rows; results are PARTIAL — add a WHERE or aggregate", h.db.MaxRows())
	}
	return out, nil
}

// sqliteTable matches DuckDB's missing-table message for a name that is
// SQLite's: the files have none of these.
var sqliteTable = regexp.MustCompile(`Table with name (v_|raw_|agg_)\w* does not exist`)

// filesError turns a failed files query into a message a model can act
// on (raw-first D21); anything else (the child could not start) passes
// through as an internal error.
func filesError(err error, timeout time.Duration) error {
	var qe *engine.QueryError
	switch {
	case errors.Is(err, context.DeadlineExceeded):
		return invalidf("query exceeded %s (CONSOLE_QUERY_TIMEOUT); narrow it with a WHERE on project_id and day, or aggregate", timeout)
	case errors.As(err, &qe) && strings.HasPrefix(qe.Msg, "Out of Memory Error"):
		return invalidf("the query ran out of the engine's memory (ENGINE_MEMORY_LIMIT). A COUNT(DISTINCT …) over a large group is the usual cause: " +
			"select the distinct values with a GROUP BY in a subquery, then count its rows; or narrow the range")
	case errors.As(err, &qe) && sqliteTable.MatchString(qe.Msg):
		return invalidf(`%s; the v_*, raw_* and agg_* tables are SQLite's: pass source "sqlite" for them. The files hold events, views, product and measures`,
			strings.SplitN(qe.Msg, "\n", 2)[0])
	case errors.As(err, &qe):
		return invalidf("SQL error (DuckDB): %s", qe.Msg)
	case errors.Is(err, engine.ErrChildExited):
		return invalidf("the query engine stopped while running the query, most likely out of memory (ENGINE_MEMORY_LIMIT); narrow the query")
	}
	return err
}

// cellText is an engine value as query's text: NULL as "" (as SQLite's
// rows read), a number in its exact text, a list or struct as JSON.
func cellText(v any) string {
	switch x := v.(type) {
	case nil:
		return ""
	case string:
		return x
	case json.Number:
		return x.String()
	case bool:
		return strconv.FormatBool(x)
	}
	b, err := json.Marshal(v)
	if err != nil {
		return fmt.Sprint(v)
	}
	return string(b)
}
```

```markdown
### Writing SQL against the event files

`query` with `source: "files"` runs one read-only `SELECT` through DuckDB
over the raw events twillingate keeps as files beside its database: every
project's, received since the upgrade that began writing them, today's
included (each `BUFFER_FLUSH_INTERVAL`). Same row cap and timeout as above;
a query cannot write and cannot reach any other file. The dialect is
DuckDB's ([duckdb.org/docs/sql](https://duckdb.org/docs/stable/sql/introduction)),
close to Postgres: `date_trunc('month', ts)`, `count(DISTINCT user_id)`,
`day BETWEEN DATE '2026-01-01' AND DATE '2026-01-31'`, `GROUP BY ALL`,
`DESCRIBE events` for the columns.

Four tables: `events`, every event of every family, and `views`, `product`
and `measures`, its rows of one family each. Every table has:

| Column | Type | |
| --- | --- | --- |
| `id`, `project_id`, `family`, `event_name` | VARCHAR, BIGINT, VARCHAR, VARCHAR | filter `project_id` (ids from `list_projects`) |
| `ts`, `received_at` | TIMESTAMP (UTC) | |
| `day` | DATE | `ts`'s UTC day |
| `kind`, `actor_id`, `actor_kind`, `user_id`, `group_id`, `session_id` | VARCHAR | |
| `host`, `path`, `referrer_source`, `utm_source`, `utm_medium`, `utm_campaign` | VARCHAR | |
| `platform`, `os`, `os_version`, `os_name`, `browser`, `browser_version`, `browser_locale`, `app_version`, `app_locale`, `device`, `device_model`, `country` | VARCHAR | as on the views (see [The event model](#the-event-model)) |
| `display_width`, `display_height` | BIGINT | |
| `consent` | BIGINT | 1, 0 or NULL |
| `value`, `measure`, `sample_rate` | DOUBLE, VARCHAR, DOUBLE | measures |
| `attr_<key>` | VARCHAR | one per attribute key any event carried, the key as sent |

- **A field the event did not send is NULL,** not `''`, and an `attr_*`
  column is NULL on every event without that key. `query` shows NULL as
  an empty string: test `IS NULL`, not `= ''`.
- **Every key is a column, declared or not.** A key with characters other
  than letters, digits and `_` needs double quotes: `"attr_plan type"`.
  Column names are not case-sensitive: `attr_Plan` and `attr_plan` are one
  column. Two such keys sent on the same day may read as `attr_plan` and
  `attr_plan_1` for that day.
- **Rules apply as you read.** An event renamed or merged reads under its
  new name and a blocked one is absent, whenever its event was stored; an
  attribute renamed or merged reads in its target's column (the target's
  own value first) and a blocked key reads NULL, on product and measures
  events. Removing a rule brings the stored names and values back.
- **A retried event can show twice** until its day closes (the day's file
  keeps each id once).
- **Filter on `project_id` and `day` or `ts`:** the files are ordered by
  family and time, and DuckDB skips what a filter excludes.

The `v_*` views and `agg_*` tables are SQLite's: name one with `files` and
the error says to pass `source: "sqlite"`. A query that runs out of the
engine's memory (`ENGINE_MEMORY_LIMIT`) is refused with that cause: a
`COUNT(DISTINCT …)` over a large group is the usual one, rewritten as a
`GROUP BY` in a subquery whose rows are then counted.
```
